# bardgui
Draw stuff on screen using vendored SDL3 library as OS layer abstraction, to be replaced by proprietary solution soon.
## USAGE
```sh
git clone --depth 1 https://github.com/onuralp-t/bardgui.git
cd bardgui
build.bat # to build the program (need `clang` on PATH)
main.exe # to run the program, after building
build.bat clean # to clean build artifacts (*.exe, *.pdb, ASAN dll)
```
